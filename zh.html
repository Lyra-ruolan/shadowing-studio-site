Shadowing Studio – Learn Languages with YouTube
最后更新：2026 年 9 月 4 日 · 对应扩展版本 0.3.0

Shadowing Studio 使用可读取的 YouTube 字幕帮助你练习语言，由 Lyra 开发。本政策说明扩展处理的数据，并单独说明访问网页或主动寻求支持时涉及的数据。

1. 扩展读取什么

扩展读取相关 YouTube 标签页的地址、视频 ID、标题及可用元信息（例如作者和时长）、字幕轨道、字幕正文和时间戳，以及播放位置、速度、暂停状态等。它们用于生成练习项、显示字幕、控制播放和生成字幕导出文件。

在匹配的 YouTube 页面上，页面桥接脚本会在文档加载时启动并观察字幕请求地址。字幕恢复可能读取文字稿面板，或打开和滚动该面板。部分页面观察可能在你打开侧边栏之前发生。扩展不读取完整的 Chrome 浏览历史数据库。

2. 本地处理与保存

字幕与播放信息在浏览器内存中处理。Chrome 扩展本地存储保存界面语言、播放模式、速度、字幕显示开关、练习粒度，以及以视频 ID 为键的字幕轨道选择。这些按视频保存的记录不是完整浏览历史，但可以识别你保存过轨道选择的视频；记录没有自动过期机制。

你主动导出时，文件在本地生成。根据格式不同，可能包含字幕文本、时间戳、视频标题、视频地址或 ID，以及字幕轨道信息。扩展不会自动上传这些文件。

3. 向 YouTube 发起的请求

扩展通过 HTTPS 请求 YouTube 的视频、字幕与转录数据，包括播放器提供的字幕地址。这些请求使用浏览器现有的 YouTube 会话。YouTube 会收到请求和正常连接信息，例如 IP 地址。

字幕恢复可能在页面内存中暂存含令牌的字幕请求地址，并使用 YouTube 的客户端或访客上下文。这些值不会保存到扩展设置或普通字幕导出文件中。扩展不要求你提供 YouTube 密码，不访问 Chrome 密码管理器，也不要求注册独立的 Shadowing Studio 账号。YouTube 根据 Google 隐私政策处理相关请求。

4. 不进行开发者统计或自动上传

扩展没有开发者运营的数据接收服务器、分析 SDK 或广告。Lyra 不会自动收到你的字幕或练习行为。扩展不录制麦克风，不捕获视频或音频，不进行发音评分，也不把字幕发送给外部 AI 服务。

Lyra 不出售扩展用户数据，不将其用于广告、信用评估或贷款资格判断。数据的使用和传输限于语言练习功能和你主动请求的支持，并遵守 Chrome Web Store 用户数据政策及其中的 Limited Use 要求。

5. 保留期限与删除

关闭或完整重新加载 YouTube 页面，会释放该页面暂存的字幕请求数据；仅关闭侧边栏不一定清除页面桥接脚本的数据。关闭侧边栏会释放其内存状态。设置与按视频保存的轨道选择会保留，直到扩展本地数据被清除或扩展被卸载。本版本没有扩展内的“一键清空所有数据”按钮。

可以在 Chrome 的扩展管理页卸载本扩展，以移除其本地扩展存储。已经导出的字幕文件仍保存在你选择的位置，需要另行删除。这不会删除 YouTube 历史记录或 Google、GitHub 持有的数据。

6. 网页托管与用户支持

本网站不包含脚本、表单、分析统计、外部字体或自动加载的第三方嵌入内容。访问托管在 GitHub Pages 上的本网站时，GitHub 可能处理 IP 地址和请求日志等连接与使用信息。点击外部链接会向对应服务发起访问。

如果你主动提交 GitHub Issue，你的 GitHub 个人资料、留言和附件可被 Lyra 和公众查看。支持信息仅用于回应请求。请勿提交密码、会话令牌、私密视频链接、未脱敏日志或其他敏感信息。发帖通常需要 GitHub 账号，阅读政策不需要账号。GitHub 的保留与删除机制由其 隐私声明约定；即使编辑或删除，公开副本也可能继续存在。
