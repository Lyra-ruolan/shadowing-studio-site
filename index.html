Shadowing Studio – Learn Languages with YouTube
Prepared September 4, 2026 · Covers extension version 0.3.0

Local draft — not published. This page and the planned GitHub Issues support channel are not live. Before publication, verify the support link, set the effective date, and remove this notice.

Shadowing Studio helps you practise languages with accessible YouTube captions. Lyra develops this extension. This policy explains data processed by the extension and, separately, data involved when you visit its future website or choose to request support.

1. What the extension accesses

The extension accesses the relevant YouTube tab's URL, video ID, title and available metadata (such as author and duration), caption tracks, caption text and timestamps, and playback state such as position, speed and whether the video is paused. It uses this information to form practice units, show captions, control playback, and create subtitle exports.

On matching YouTube pages, a page bridge starts when the document loads and observes caption-request URLs. Caption recovery may read the transcript panel or open and scroll it. Some page observation can occur before you open the side panel. The extension does not read your full Chrome browsing-history database.

2. What stays on your device

Captions and playback information are processed in browser memory. Chrome's local extension storage keeps interface language, playback mode, speed, caption visibility, practice granularity, and selected caption tracks keyed by video ID. These per-video records are not a full browsing history, but can identify videos for which you saved a track choice. They have no automatic expiry.

When you request an export, a file is generated locally. Depending on the format, it can include subtitle text, timestamps, video title, video URL or ID, and track metadata. The extension does not automatically upload these files.

3. Requests to YouTube

The extension makes HTTPS requests for YouTube video, caption and transcript data, including caption addresses supplied by the player. These requests use your browser's existing YouTube session. YouTube receives the requests and normal connection information such as your IP address.

Caption recovery may temporarily retain token-bearing caption-request URLs and use YouTube's client or visitor context in page memory. These values are not saved in the extension's preference storage or ordinary subtitle exports. The extension does not ask for your YouTube password, access Chrome's password manager, or require a separate Shadowing Studio account. YouTube processes its requests under Google's Privacy Policy.

4. No developer analytics or automatic uploads

The extension has no developer-operated collection server, analytics SDK or advertising. Lyra does not receive your captions or practice activity automatically. It does not record your microphone, capture video/audio, score pronunciation, or send captions to an external AI service.

Lyra does not sell extension user data, use it for advertising, or use it to assess creditworthiness or lending eligibility. Use and transfer of user data are limited to the language-practice features and support you request, consistent with the Chrome Web Store User Data Policy, including its Limited Use requirements.

5. Retention and deletion

Closing or fully reloading a YouTube page releases that page's temporary caption-request data; merely closing the side panel does not necessarily clear the page bridge. Closing the side panel releases its in-memory state. Local preferences and per-video track choices remain until the extension's local data is cleared or the extension is uninstalled. There is no in-extension clear-all button in this version.

You can uninstall the extension through Chrome's extension-management page to remove its local extension storage. Downloaded subtitle files remain wherever you saved them and must be deleted separately. This does not remove YouTube history or data held by Google or GitHub.

6. Website hosting and support

This local page has no scripts, forms, analytics, remote fonts or automatic third-party embeds. If you later visit a copy hosted on GitHub Pages, GitHub may process connection and usage information such as IP addresses and request logs. Following an external link makes a request to that service.

If you choose to submit a GitHub Issue, your GitHub profile, message and attachments can be seen by Lyra and the public. Support information is used to respond to the request. Do not post credentials, session tokens, private video links, unredacted logs or other sensitive information. Posting an Issue generally requires a GitHub account; reading the policy does not. GitHub's retention and deletion controls are governed by its Privacy Statement; public copies may remain after editing or deletion.
